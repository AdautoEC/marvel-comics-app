# Wave 1: Data Integrity & Security Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resolve critical P0 data integrity and security vulnerabilities by implementing a composite primary key `(id, category)` in Room, explicit non-destructive migrations (`MIGRATION_2_3`), fail-closed CI release signing, and CSRF protection on TMDB OAuth callbacks.

**Architecture:** 
1. Database integrity is preserved by elevating `MovieEntity` to a composite primary key `(id, category)` so movies existing in multiple categories (e.g., Populares and Mais Votados) coexist without overwriting row state or relative position. Room schema migrations are made non-destructive and explicit, removing `.fallbackToDestructiveMigration()`.
2. Release signing switches from fail-open (`initWith(debug)`) to fail-closed when executing production tasks (`CI_RELEASE_BUILD=true` or `bundleRelease`), preventing accidental distribution of debug-signed artifacts.
3. OAuth callbacks validate an in-memory `pendingRequestToken` with a 10-minute TTL to prevent deep link injection / session hijacking attacks.

**Tech Stack:** Kotlin 2.0.21, AndroidX Room 2.6.1 with KSP schema export, Robolectric 4.14 / AndroidX Test, Gradle 8.7.2, GitHub Actions.

**Spec:** [`docs/superpowers/specs/2026-10-23-cinema-hub-hardening-design.md`](file:///Users/adautosouza/repos/estudos/docs/superpowers/specs/2026-10-23-cinema-hub-hardening-design.md)

## Global Constraints

- **Zero Data Loss on Schema Migrations:** Existing user data (`favorite_movies` and `watched_movies`) must never be wiped by Room schema evolution. Room schema version 3 must migrate cleanly from version 2 without destructive fallback.
- **Fail-Closed Release Engineering:** Production publishing jobs (`main-cd.yml` with `CI_RELEASE_BUILD=true`) must halt immediately with descriptive errors if release keystore or production credentials are absent. Local developer builds and PR builds testing R8 (`assembleRelease`) retain debug fallback.
- **OAuth Callback Isolation:** `completeAuthentication(requestToken)` must reject any token that was not explicitly generated by `createRequestToken()` in the current session or that has exceeded the 10-minute TTL.
- **Detekt & Lint Cleanliness:** Zero new Detekt code smells, zero lint errors, 100% test pass rate across all modules.
- **Documentation Preservation:** All plans and temporary superpower documents remain local in `docs/` and `.superpowers/` (both in `.gitignore`).

## Review Focus

1. **Multi-category row coexistence:** A movie with ID 550 appears in both `POPULAR` (position 1) and `TOP_RATED` (position 4). Upserting `TOP_RATED` must not delete, overwrite, or mutate the `POPULAR` record.
2. **Schema migration preserving user tables:** Running `MIGRATION_2_3` transforms the `movies` table to composite PK `(id, category)` while leaving existing entries in `favorite_movies` and `watched_movies` completely intact.
3. **Missing release secrets during CD build:** Executing Gradle release tasks with `CI_RELEASE_BUILD=true` when `KEYSTORE_FILE` is missing or invalid must fail the build with a `GradleException`, never quietly producing a debug-signed bundle.
4. **OAuth CSRF token mismatch:** An attacker or rogue app triggering `marvelapp://tmdb-callback?request_token=forged_token&approved=true` must be rejected with `DomainError.InvalidKey` without triggering token exchange or local data push.
5. **OAuth token expiration / replay:** Calling `completeAuthentication` with an expired token (>10 minutes) or attempting to reuse a previously consumed token must fail and not leave hanging pending state.

```kotlin
package com.adauto.marvel.core.database.migrations

import androidx.room.migration.Migration
import androidx.sqlite.db.SupportSQLiteDatabase

val MIGRATION_2_3 = object : Migration(2, 3) {
    override fun migrate(db: SupportSQLiteDatabase) {
        db.execSQL("""
            CREATE TABLE IF NOT EXISTS `movies_new` (
                `id` INTEGER NOT NULL,
                `category` TEXT NOT NULL,
                `position` INTEGER NOT NULL,
                `title` TEXT NOT NULL,
                `overview` TEXT NOT NULL,
                `posterPath` TEXT,
                `backdropPath` TEXT,
                `voteAverage` REAL NOT NULL,
                `releaseDate` TEXT,
                `runtime` INTEGER,
                `genresJson` TEXT,
                `castJson` TEXT,
                `fetchedAt` INTEGER NOT NULL,
                PRIMARY KEY(`id`, `category`)
            )
        """.trimIndent())

        db.execSQL("""
            INSERT OR REPLACE INTO `movies_new` (
                `id`, `category`, `position`, `title`, `overview`, 
                `posterPath`, `backdropPath`, `voteAverage`, `releaseDate`, 
                `runtime`, `genresJson`, `castJson`, `fetchedAt`
            )
            SELECT 
                `id`, `category`, `position`, `title`, `overview`, 
                `posterPath`, `backdropPath`, `voteAverage`, `releaseDate`, 
                `runtime`, `genresJson`, `castJson`, `fetchedAt`
            FROM `movies`
        """.trimIndent())

        db.execSQL("DROP TABLE `movies`")
        db.execSQL("ALTER TABLE `movies_new` RENAME TO `movies`")
        db.execSQL("CREATE UNIQUE INDEX IF NOT EXISTS `index_movies_category_position` ON `movies` (`category`, `position`)")
    }
}
```

```kotlin
signingConfigs {
    create("release") {
        val keystorePath = System.getenv("KEYSTORE_FILE") ?: project.findProperty("KEYSTORE_FILE") as? String
        val storePasswordEnv = System.getenv("KEYSTORE_PASSWORD") ?: project.findProperty("KEYSTORE_PASSWORD") as? String
        val keyAliasEnv = System.getenv("KEY_ALIAS") ?: project.findProperty("KEY_ALIAS") as? String
        val keyPasswordEnv = System.getenv("KEY_PASSWORD") ?: project.findProperty("KEY_PASSWORD") as? String
        val isPublishingOrCD = System.getenv("CI_RELEASE_BUILD") == "true" ||
            gradle.startParameter.taskNames.any { it.contains("bundleRelease", ignoreCase = true) }

        if (!keystorePath.isNullOrBlank() && file(keystorePath).exists() && !storePasswordEnv.isNullOrBlank()) {
            storeFile = file(keystorePath)
            storePassword = storePasswordEnv
            keyAlias = keyAliasEnv
            keyPassword = keyPasswordEnv
        } else if (isPublishingOrCD) {
            throw GradleException("Production release signing configuration (KEYSTORE_FILE/PASSWORD/ALIAS) is missing or invalid.")
        } else {
            // Local dev / PR verification with assembleRelease falls back to debug signing to verify R8 minification
            initWith(getByName("debug"))
        }
    }
}
```

```kotlin
private const val TOKEN_TTL_MS = 10 * 60 * 1000L // 10 minutes

// In AuthRepositoryImpl:
@Volatile
private var pendingRequestToken: String? = null
@Volatile
private var pendingTokenCreatedAtMs: Long = 0L

override suspend fun createRequestToken(): Outcome<String> {
    return when (val response = api.createRequestToken()) {
        is ApiResponse.Success -> {
            val token = response.data.request_token
            pendingRequestToken = token
            pendingTokenCreatedAtMs = System.currentTimeMillis()
            Outcome.Success(token)
        }
        is ApiResponse.Failure -> Outcome.Failure(response.toDomainError())
    }
}

override suspend fun completeAuthentication(requestToken: String): Outcome<TmdbAccountDto> {
    val pending = pendingRequestToken
    val createdAt = pendingTokenCreatedAtMs
    val now = System.currentTimeMillis()

    if (pending.isNullOrBlank() || pending != requestToken || (now - createdAt) > TOKEN_TTL_MS) {
        pendingRequestToken = null
        return Outcome.Failure(DomainError.InvalidKey)
    }

    // Clear pending token to prevent replay attacks
    pendingRequestToken = null

    val sessionResponse = api.createSession(TmdbCreateSessionRequestDto(requestToken))
    // ... rest of session creation
}

override suspend fun logout() {
    pendingRequestToken = null
    sessionManager.clearSession()
    database.favoriteDao().clearAll()
    database.watchedDao().clearAll()
}
```
